Status pill for enums (status, forecast category, stage, severity).

```jsx
<Badge uppercase>OPEN</Badge>
<Badge tone="brand">75% · Commit</Badge>
<Badge tone="critical" icon={<Icon name="OctagonAlert" size={12} />}>Critical</Badge>
```

Never a colour alone: risk tones always carry an icon or a word. Use `RiskBadge` for health/risk specifically.
