# Sales Intelligence Platform

## Phase 1 Client Acceptance Checklist

This checklist supports a stakeholder review of the accepted staging baseline. It is not a legal signature instrument.

Review baseline: `phase-1-uat-accepted` → `de23454048f22bf2deac295630235c181b661c04`

### Dashboard

- [ ] The dashboard answers whether the quarter is likely to reach quota.
- [ ] Quota, billed, forecast, gap, Commit, backlog, coverage and GM are understandable.
- [ ] Missing configuration is clearly distinguished from a real zero.

### Forecast

- [ ] Open forecast represents current-quarter Best Case plus Commit.
- [ ] Future-quarter opportunities do not inflate current-quarter coverage.
- [ ] The projected gap definition matches management expectations.

### Funnel

- [ ] The 20/40/60/80/90 stages match the agreed commercial methodology.
- [ ] Stage 100 is understood as terminal billed revenue, not open funnel.
- [ ] Lost and Cancelled preserve commercial history appropriately.

### Opportunities

- [ ] The opportunity record contains the information needed for commercial review.
- [ ] The drawer provides sufficient context without leaving the dashboard.
- [ ] Ownership, next action, dates, forecast and history are clear.

### GM

- [ ] GM % is aligned with seller practice.
- [ ] Derived gross profit is understandable.
- [ ] The tenant margin threshold reflects management policy.

### Qualification

- [ ] The 60% qualification questions are sufficient.
- [ ] The 80% qualification questions are sufficient.
- [ ] Evidence requirements improve confidence without creating unnecessary work.

### Review

- [ ] Forecast Review can support the weekly management meeting.
- [ ] Keep Commit / Move to Upside decisions are understandable.
- [ ] Ask Seller, seller response, notes and history provide sufficient traceability.

### Alerts

- [ ] Alerts are understandable and explain why attention is required.
- [ ] The alert set reflects the most important Phase 1 commercial risks.
- [ ] Alerts are not being mistaken for predictive AI.

### Billing and quota

- [ ] Billing facts are accepted as the source of actual revenue.
- [ ] Won/pending billing and Billed are clearly distinguished.
- [ ] Tenant and optional seller quotas meet the agreed reporting need.

### Brand performance

- [ ] Quota, billed, forecast, Commit, projected gap and GM by brand are sufficient.
- [ ] Missing brand quota is clearly shown as not configured.

### Import

- [ ] Analyze → Map → Confirm → Validate → Execute is understandable.
- [ ] Dry-run and blocking conditions provide sufficient control.
- [ ] The real source for `Facturado Daily` has been identified or recorded as pending.

### Roles

- [ ] Tenant Admin responsibilities are appropriate.
- [ ] Manager team scope is appropriate.
- [ ] Seller own scope is appropriate.
- [ ] Executive and Viewer read-only access is appropriate.

### Responsive

- [ ] Manager workflow is usable on the expected desktop environment.
- [ ] Seller workflow is usable at 390 px mobile width.
- [ ] Spanish and English layouts remain readable.

### Security

- [ ] Tenant, team and seller access boundaries match business expectations.
- [ ] Read-only profiles expose no mutation controls.
- [ ] Customer production remains separate from the staging review.

### Open external items

- [ ] The real `PROGRAMA VENTAS.xlsx` source has been provided for customer-specific mapping.
- [ ] Hosted SMTP ownership and configuration have been agreed.
- [ ] Any future corporate identity requirement has been recorded separately.

## Acceptance decision

- [ ] Accepted with observations
- [ ] Changes required before acceptance
