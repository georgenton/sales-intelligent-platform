## Smallest UX Sprint 1.1 Merge Gate

The smallest merge-oriented Sprint 1.1 is **not** “complete every PARTIAL component.” It removes the
five P0 risks and explicitly accepts P1/P2 items as scheduled follow-up debt.

### 1. Decision-safe revenue semantics

- `QuotaProgress`: model quota as available/unavailable rather than converting absence to zero; add
  real attainment text, no-quota, loading, and scoped-error states.
- `ForecastConfidence`: stop substituting opportunity health for system confidence. Accept a nullable
  confidence/alignment contract and render “not yet computed” until the backend supplies a real result.
  When present, render the explicit Aligned/Disagreement word.

### 2. Accessible Copilot overlay

- Trap and restore focus in tablet/mobile overlay modes.
- Close with Escape and scrim.
- Add a polite message live region.
- Preserve the question after failure and expose a deterministic retry.
- Render the static Working state; full multi-message persistence and proactive evidence remain Sprint
  2 unless already available from the existing response.

### 3. Safe import mapping and validation

- `ImportMapper`: give every select a source-column label; reject `.xlsx` explicitly until a real parser
  is wired; add no-header and parse-failure recovery; surface confidence without fabricating it.
- `DataQualityPanel`: replace hardcoded duplicate zero with `not checked` or a real local result; block
  mutation when validation is incomplete; say exactly which rows will import; add validation retry and
  severity words. Cross-checking existing tenant records may remain Sprint 2 if the UI says it was not
  performed.

### 4. Required verification

- Component tests for every P0 empty/loading/error state.
- Keyboard and focus tests for Copilot overlay.
- Import tests for unsupported workbook, missing header, invalid rows, partial-ready rows, and
  validation failure.
- Decision-integrity tests proving missing quota/confidence never renders as numeric zero or a derived
  health confidence.
- Existing format, lint, typecheck, unit, integration, tenant/RLS, build, Gitleaks, dependency audit,
  and Playwright flows remain green.

## Sprint 1.1 Exit Criteria

PR #3 can be recommended merge-ready after review only when:

1. All five P0 rows above are resolved or explicitly waived in writing.
2. No unavailable commercial metric is represented as zero or inferred from a different metric.
3. No import can start while mapping/validation status is unknown.
4. Copilot overlay is keyboard-contained, Escape-closeable, focus-restoring, and retryable.
5. P1/P2 items have individual follow-up issues with the priorities and target sprints in this plan.
6. The complete quality/security/E2E gate is green.

This plan does not authorize implementation or merge PR #3.
